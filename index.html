使用说明
  1. 双击 打开演示.bat（自动调用 Chrome / Edge）或直接双击 index.html 打开页面；首次运行需联网自动加载 MediaPipe 姿态模型（约 10MB，之后走浏览器缓存）。
  2. 点击「开启摄像头」并允许权限，站在镜头前约 1~2 米，尽量让上半身与膝盖完整入镜。
  3. 动作演示（8 种）：举手过头 → 金色星光迸发；屈膝下蹲 → 樱花飘落；坐姿 → 萤火虫环绕；自然站立 → 粒子光晕；双手合十于胸前 → 爱心升腾；双臂侧平举 T 字 → 绿色光环波纹；高抬腿 → 脚下冲击波粒子；双脚起跳 → 彩色纸屑爆发。
  4. 场景切换：点击海洋（气泡上浮）/ 森林（落叶飘散）/ 夜晚星空（繁星闪烁）切换不同背景与环境粒子效果。
  5. 「识别灵敏度」越高动作越容易触发；低配笔记本建议开启流畅模式（降低推理频率与粒子数量）。
  6. 画面仅在本机浏览器内实时处理，不上传、不保存，可放心演示。
